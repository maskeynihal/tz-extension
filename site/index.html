Three ways to read a time right.

Every feature works where you already are — on the page, in a popup, no context-switching.

✶

Select to convert

Highlight any time on any page. A small card shows it in your zones, right next to the text. Pin cards to compare several at once — each keeps its own colored highlight.

◳

Full converter

A popup converter: pick a date and source zone, hit Local, and read it across every zone you care about. 12/24-hour, DST-correct.

⧖

Epoch & formats

Paste a Unix timestamp (seconds or milliseconds, auto-detected) or almost any written date. Add your own custom formats for the ones only your systems use.

Install in a minute.

Grab the latest release, then load it unpacked. Store listings coming soon.

Download

Get tz-extension-chrome.zip or tz-extension-firefox.zip from the latest release and unzip it.

Load it

Chrome/Edge: chrome://extensions → Developer mode → Load unpacked.
Firefox: about:debugging → Load Temporary Add-on → pick manifest.json.

Use it

Select any time on a page, or click the toolbar icon for the full converter. That's it.
